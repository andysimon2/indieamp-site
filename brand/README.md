# IndieAmp brand sources

Logo mark "1B": four centered capsules, the fourth in a lighter green. Chosen 2026-10-14.

| File | Use |
|---|---|
| `mark.svg` | the mark on light backgrounds (dark green + light green) |
| `mark-reversed.svg` | the mark on the dark green |
| `mark-mono.svg` | one color (black); recolor as needed |
| `favicon.svg`, `favicon.ico`, `favicon-32.png` | browser tab icon |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | app / home-screen icons |
| `previous-favicon.svg` | the baseline-aligned bars used before 2026-10-14 (kept for the comparison page) |
| `IndieAmp_logo_1B_comparison.html` | old vs new, side by side (not linked from the site) |

Colors: dark `#173b30`, light bar `#5E9A7C`, cream `#f8f6ef`, mint (on dark) `#86C3A4`.
The header mark on the site is drawn in CSS (`.mark` in each page), not from these files; the icons in the site root are copies of the ones here.
Everything in this repo is served publicly by Vercel and visible on GitHub: do not put drafts, client files or anything private here.
